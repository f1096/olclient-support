OlClient 支持

面向 iPhone、iPad 和 Apple 芯片 Mac 的独立原生 OpenList 客户端；各平台版本是否已可下载，以 App Store 实际状态为准。

联系支持：fat.fox.1096@icloud.com

开始使用

在网盘页点击右上角“+”，输入你自己的 HTTPS OpenList 服务地址及账号。可以填写别名，保存后切换连接。OlClient 不提供网盘空间、媒体内容或服务器部署服务，与 OpenList 团队及网盘提供方无隶属关系。

连接或登录失败

请确认服务能从设备当前网络访问，HTTPS 证书有效，账号权限正确。需要两步验证时输入当前验证码。保存的会话过期时请重新登录；不要关闭系统证书校验。

下载、预览与上传

文件菜单的“下载”会先打开系统“文件”选择保存位置，然后开始下载。进度可在任务页查看。目录下载先扫描并确认；同名目标不会直接覆盖。预览能力和起播速度取决于格式、网络及存储提供方。不支持的格式可用系统分享交给其他应用。上传时请保持应用在前台。

离线文件与数据管理

已有本机副本可从离线文件入口访问；该入口可能需要设备身份验证。删除连接、退出服务与删除本机下载是不同操作。远端文件与账号由你配置的服务管理，移除本 App 不会删除服务器上的文件。

Mac 版本

需要 Apple 芯片及 macOS 14 或更新版本。当前支持原生文件浏览、图片/PDF/文本预览和前台传输；音视频可下载后用其他应用打开。可在设置中设置、修改或移除六位数字启动 PIN，修改和移除需原 PIN。PIN 无法找回，不保护已导出的文件。下载选择本机目录，由访达管理导出文件。

反馈问题

请提供 App 版本、系统版本、设备型号、操作步骤和不含私人资料的截图。请勿发送密码、验证码、服务令牌、带签名的下载链接或私人文件。

OlClient Support

An independent native OpenList client for iPhone, iPad and Apple Silicon Mac. Platform availability is determined by the actual App Store listing. Contact fat.fox.1096@icloud.com.

Add your own reachable HTTPS server and account using + on Drivers. OlClient provides no cloud storage, media catalog or server deployment, and is not affiliated with OpenList or storage providers.

For connection problems, check network reachability, valid HTTPS certificates, account permissions and any current two-step code. Sign in again when a saved session expires.

Download opens the system Files destination picker before transferring. Inspect progress in Tasks. Folder downloads require scanning and confirmation, and existing destinations are not silently overwritten. Preview formats and speed depend on the file, network and provider. Unsupported files can be shared to another app. Keep the app in the foreground for uploads.

Offline access may require device authentication. Removing a connection, signing out and deleting downloaded copies are separate actions. Files and accounts on your own server remain under its control.

The Mac version requires Apple Silicon and macOS 14+. It supports native file browsing, image/PDF/text previews and foreground transfers. Download audio/video to open it in another app. Settings provides an optional six-digit startup PIN; changing or removing it requires the current PIN. PIN recovery is unavailable, and the PIN does not protect exports in Finder.

For support, include app and OS versions, device model and reproduction steps. Never send passwords, one-time codes, tokens, signed download links or private files.
